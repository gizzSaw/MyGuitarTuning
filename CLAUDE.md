# MyGuitarTuning — заметки для Claude

Статичная веб-страница: выбираешь строй гитары и тональность, и она показывает ноты открытых
струн и ноты на грифе до 12-го лада с подсветкой тональности. Чистые HTML + CSS + vanilla JS,
без сборки, без зависимостей, без тестов. Upstream: `github.com/gizzSaw/MyGuitarTuning`.
Владелец (gizzSaw) — это сам пользователь, автор коммитов задан в `.git/config`.

## Запуск

Открыть `index.html` в браузере (или `python3 -m http.server` в корне проекта и зайти на
`localhost:8000`). Собирать и устанавливать ничего не нужно.

| `js/sound.js` | Весь звук: струны, гамма, аккорды, ноты-фишки, ноты грифа, клавиши пианино (Web Audio, Карплус — Стронг) |

| `css/piano.css` | Пианино: белые клавиши flex-рядом, чёрные поверх по `--pos`, подсветка |
| `css/neck.css` | Гриф: две раскладки (горизонтальная / вертикальная), струны, лады, точки, ноты, подсветка |
| `img/img.JPG` | Картинка головки грифа, фон ровно `#252527` |

(2026-11-17): Helvetica убрана при редизайне, а фальшивые `.woff2` (на самом деле PostScript Type 1) — ещё раньше.

## Интерфейс

Сетка `.main` (`grid-template-areas`): на ширине ≥ 900px «Tuning» слева на две строки, справа «Key» и
«Chord» друг под другом, «Fretboard» и «Piano» — во всю ширину снизу; уже — всё в одну колонку. Каждая карточка — `.card` с заголовком `.card__title`.

1. **Tuning** (`.tuning`): головка грифа (`.app__inner`) с 6 окошками-кнопками `.app__notes-item_stringN`
   (клик — звучит струна, см. «Звук»).
   Слева сверху вниз — струны 4, 5, 6 (D A E), справа — 3, 2, 1 (G B E), как колки на головке 3+3.
   Номер струны в углу окошка — это `::before` с `content: attr(data-string)`: JS перезаписывает
   `textContent` окошка, а псевдоэлемент остаётся. Под головкой `.control`: кнопки `−`/`+`
   (`.control__btn_prev/next`) сдвигают строй на полутон, в центре название строя
   (`.control__drop` «Drop» + `#currentTuning` + `.control__std` «Standard», лишнее скрыто атрибутом
   `hidden`) и `.control__notes` — строка вида `E A D G B E`. Ниже переключатель `.tuning-type`
   Standard | Drop.
2. **Key** (`.key`): `select#keyRoot` (тоника; `""` = Off) и переключатель `.key__types`
   Major | Minor | Blues, под ними `.key__notes` — ноты гаммы фишками (`.chip`, тоника
   `.chip_root`) или подсказка `.hint`.
3. **Chord** (`.chord`): `select#chordRoot` (`""` = Off) и `select#chordQuality` (опции заполняет `neck.js`
   из `CHORDS`), под ними `.chord__notes` — ноты аккорда фишками со ступенями (`R 3 5 ♭7`). Ниже
   `.chord__key` — аккорды выбранной тональности кнопками `.chord__item` с римскими цифрами и
   переключатель `.chord__size` Triads | 7th (скрыт, пока тональность не выбрана). Клик по аккорду
   выставляет оба select, повторный клик — выключает аккорд.
4. **Fretboard** (`.guitar-neck__inner`): в заголовке легенда `.legend` (её пункты рисует `neck.js`); ноты кликабельны; `.fret_0` … `.fret_12`, в каждом `.string1` (тонкая E) …
   `.string6` (толстая E), в каждой — `.note`.

5. **Piano** (`.piano__keys`): клавиши — `<button class="piano__key piano__key_white|_black" data-midi data-note>`,
   их строит `piano.js`. Диапазон C3…C5; на ширине ≤ 560px нижняя октава (`.piano__key_low`) скрыта и
   `--offset: 7` сдвигает чёрные клавиши. Подсветка — `piano__key_root/_tone/_key` (те же цвета, что на грифе).

Фишки нот (`.chip`) в «Key» и «Chord» — `<button>`: по нажатию звучат.

**Переключатели** (`.segmented`): активная кнопка — та, у которой `aria-pressed="true"`;
её подсвечивает CSS, отдельного класса нет. JS при клике выставляет `aria-pressed` всем кнопкам группы.

## Как работает `main.js`

**Состояние хранится в DOM**, отдельных JS-переменных почти нет:
- текущая тоника = `#currentTuning.textContent` (при старте `"E"`);
- дроп или нет = `let isDropped` (строка 19).

**Модель нот:** `NOTES = ['C','C#',…,'B']` (12 полутонов, только диезы, без бемолей).
Нота хранится как индекс в этом массиве.

**Расчёт строя** (`changeTuning`):
1. Берёт индекс текущей тоники, `'next'` / `'prev'` → ±1 с переходом по кругу (11↔0).
2. `setIntervals()` возвращает интервалы от 6-й струны в полутонах, взятые по модулю 12:
   - Standard: `[0, 5, 10, 3, 7, 0]` (струны 6→1) → для E: `E A D G B E`;
   - Drop: все, кроме 6-й, +2 → `[0, 7, 12, 5, 9, 2]` → для D: `D A D G B E` = Drop D.
     То есть «Drop X» — 6-я струна на X, остальные как в стандартном строе на тон выше.
3. `writeCorrectNote` → `returnNoteToOctave(interval, idx)` = `NOTES[(idx + interval) % 12]`.
4. Обновляет `.control__notes`, вызывает `changeNotesOnNeck()`, затем `highlightNeck()` из `neck.js`.

**Перерисовка грифа** (`changeNotesOnNeck`, стр. 341, в `main.js`, а не в `neck.js`):
- 78 `querySelector` на каждую клетку (`fret{N}string{M}`) собраны в 13 массивов
  `stringsOnFret0..12` (порядок струн 1→6);
- лад 0 = нота открытой струны (берётся из окошек головки), каждый следующий лад = предыдущий +1
  полутон. Эти 12 блоков отличаются только номером лада, их легко свернуть в цикл.

**Инициализация:** последней строкой файла вызывается `changeTuning()` без аргумента, и всё рисуется для E Standard.
Скрипты подключены с `defer`, так что DOM к этому моменту уже готов.

**Обработчики:** `prevBtn` → `changeTuning('prev')`, `nextBtn` → `changeTuning('next')`,
кнопки `.tuning-type` → `setDropped(true/false)`: ставит флаг, `aria-pressed`, показывает «Drop»
или «Standard» в названии и вызывает `changeTuning()` без направления, то есть просто пересчитывает.

## Теория (`theory.js`) и подсветка (`neck.js`)

- `SCALES` — ступени в полутонах от тоники: major `[0,2,4,5,7,9,11]`, minor (натуральный)
  `[0,2,3,5,7,8,10]`, blues (минорная блюзовая, 1 b3 4 b5 5 b7) `[0,3,5,6,7,10]`.
  Новый тип гаммы = ключ в `SCALES` + кнопка `data-scale="…"` в `.key__types` + подпись в `SCALE_LABELS` (`neck.js`).
- `CHORDS` — `{ suffix, label, intervals }`; новый тип аккорда достаточно добавить сюда, в select он попадёт сам.
  `DEGREES` переводит интервал в ступень (`10` → `♭7`).
- `getKeyChords(root, type, size)`: для 7-ступенных гамм на каждой ступени складывает ноты гаммы
  через одну (терциями) и находит тип аккорда по интервалам (`findChordQuality`); C major →
  C Dm Em F G Am Bdim, септаккорды → Cmaj7 Dm7 Em7 Fmaj7 G7 Am7 Bm7♭5. Блюз (6 ступеней) —
  особый случай: I IV V (или I7 IV7 V7). Римские цифры — `getNumeral` (минорные строчными, `°`, `ø7`).
- Состояние: тональность — `keyRootSelect.value` + `let keyType`; аккорд — `chordRootSelect.value`
  + `chordQualitySelect.value`; размер аккордов тональности — `let chordSize` (3 | 4).
- `highlightNeck()` проходит по всем 78 `.guitar-neck .note` и ставит модификаторы:
  выбран аккорд — его основной тон `note_root`, остальные ноты аккорда `note_tone`, ноты тональности
  не из аккорда `note_key` (контур); аккорд не выбран — то же для тональности (без `note_key`);
  остальные `note_out`. Затем перерисовывает фишки тональности, аккорды тональности, ноты аккорда
  и легенду. Вызывается на любое изменение в карточках и из `changeTuning()`.
- Названия нот только с диезами (как в `NOTES`), поэтому, например, F major показывается с A#, а не с Bb.

**Порядок скриптов важен:** `theory.js` → `piano.js` → `neck.js` → `main.js` → `sound.js`. `NOTES` и
остальная теория нужны всем, поэтому `theory.js` первый (`NOTES` перенесён туда из `main.js`); `piano.js`
при загрузке строит клавиши по `NOTES`; `main.js` при запуске (`changeTuning()` в конце файла) уже
вызывает `highlightNeck()` → `highlightPiano()`; `sound.js` вешает обработчики на всё и пользуется
глобальными переменными остальных файлов. Глобальные `const`/`let` всех файлов не должны совпадать
по имени, иначе будет SyntaxError.

## Звук (`sound.js`)

- Клик по окошку струны играет её ноту на реальной высоте. Октава — ближайшая к стандартной высоте
  струны (`STANDARD_MIDI`: E2 A2 D3 G3 B3 E4), от −6 до +5 полутонов: D Standard → D2 G2 C3 F3 A3 D4,
  Drop D → D2 A2 D3 G3 B3 E4. Нота читается из `textContent` окошка в момент щипка.
- `synthesizePluck` — Карплус — Стронг: линия задержки с шумом + усреднение соседних отсчётов +
  allpass-фильтр на дробную часть периода. Высота точная (проверено автокорреляцией: ≤ 0,11 цента
  на 44,1 и 48 кГц) — это эталон для настройки, не ломать точность. Буферы кэшируются по MIDI-номеру.
- `AudioContext` создаётся при первом клике (иначе браузер не разрешает звук). На выходе компрессор,
  чтобы аккорды не перегружали звук. `playMidi(midi, when, volume)` — общая функция для любой ноты;
  `releaseVoice` гасит ноту (повторно не гасит — старый Safari падает на втором `stop()`).
- Одиночные ноты (`playNote`): фишки в «Key»/«Chord» звучат в 3-й октаве от тоники (как гамма),
  нота грифа — открытая струна + номер лада (`neckNoteMidi`), клавиша пианино — `data-midi`.
  `onPress`: мышью — сразу на `pointerdown`, пальцем — по `click` (иначе прокрутка грифа на телефоне
  играла бы ноты), клавиатурой — по `click` с `detail === 0`.
- «Play scale» — гамма вверх до октавы (тоника C3…B3), бегущий огонь по фишкам, грифу и пианино.
  «Play chord» и клик по аккорду тональности — бой: `getChordVoicing` (бас E2…D#3, сверху квинта,
  октава, терция, квинта, септима; Am → A2 E3 A3 C4 E4). «Play all» в «Chords in key» — аккорды
  тональности по очереди с возвратом на I, выбирая каждый (гриф следует). Любое изменение
  пользователем прерывает последовательность (`stopSequence`).
- «Repeat» (`aria-pressed`): клик по струне повторяет её каждые 2,5 с (`app__notes-item_active`),
  повторный клик — стоп. «Play all» — струны 6→1 с шагом 350 мс. Строка `.sound__status` —
  «String 6 · E2 · 82.41 Hz».
- В headless Chrome звук проверяется с `--autoplay-policy=no-user-gesture-required --mute-audio`;
  на скриншотах с `--virtual-time-budget` анимации и переходы замирают на первом кадре — для
  проверки итогового вида отключай их стилем в iframe.

## Гриф (`neck.css`)

- **Две раскладки на одной разметке.** По умолчанию горизонтальная: лады — колонки, струны —
  строки, 1-я струна сверху. На ширине ≤ 560px вертикальная: `.guitar-neck__inner` становится
  `flex-direction: column`, каждый `.fret` — строкой с `flex-direction: row-reverse` (в разметке
  струны идут 1→6, а слева должна быть 6-я, как в аккордовых схемах).
- Размеры — CSS-переменные на `.guitar-neck__inner` (`--row`, `--note`, `--note-font`, `--open-size`,
  `--fret-size`), media-запросы (760 / 560 / 360px) меняют только их и направление.
- Струна — `.string::before`, линия через центр клетки; толщина `--gauge` растёт от `.string1` (1px)
  к `.string6` (3px). Лад — `border-right` у `.fret` (в вертикальной раскладке `border-bottom`),
  порожек — толстая граница `.fret_0`. На ладу 0 струн нет: там только подписи открытых струн.
- Точки: `::after` у `.fret_3/5/7/9` и `::before` + `::after` у `.fret_12`, по центру лада.
  Размер 8px, чтобы помещаться в зазор между кружками нот.
- `.fret-number` стоит внутри `.string1` каждого лада (у лада 0 закомментирован) и абсолютным
  позиционированием выносится над грифом (горизонтально) или справа от него (вертикально).
- `.note` — кружок по центру клетки (`left/top: 50%; transform: translate(-50%, -50%)`).
- Подсветка: `note_root` — заливка `--root` + белое кольцо `box-shadow`, `note_tone` — заливка
  `--accent`, `note_key` — золотой контур, `note_out` — серый текст `--muted`. На ладу 0 кружков нет — там те же цвета у текста.
  Правила подсветки стоят после базовых и с двойным классом, чтобы перебить `.fret_0 .note`.

## Что важно помнить

- `console.log(currentTuningIndex)` (стр. 76) с комментарием автора «очень важен, не удаляй» — **не удалять**.
- `--surface: #252527` = фон `img/img.JPG`. Если поменять цвет карточек, вокруг картинки будет
  виден прямоугольник. Низ картинки растворяется через `mask-image`.
- Чтобы что-то скрыть, используй атрибут `hidden` (в `style.css` есть `[hidden] { display: none !important }`).

## Как проверять изменения

Скриншоты: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new
--screenshot=out.png --window-size=1280,1000 file://$PWD/index.html`. Headless Chrome не делает
окно уже ~500px, поэтому мобильные ширины (и вертикальный гриф) проверяй через страницу с
`<iframe width="320">`, открытую с локального `python3 -m http.server`. Тогда из iframe можно
читать DOM, кликать кнопки и сверять ноты с `NOTES[(open + fret) % 12]`, а классы подсветки —
с гаммой из `SCALES`. Проверять стоит ширины 320, 375, 414, 600, 760 и 1280.
